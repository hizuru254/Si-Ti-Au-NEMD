# 自主设计循环（Human-on-the-loop）

> 目标：人类只做两次判断——**锚点是否可信**、**最终候选是否合理**。
> 其余（设计几何、跑 NEMD、QC、比较、提出下一批、收敛）全部由 AI 完成。

本文档描述“从人工指挥”升级到“AI 自主找最优”的完整闭环，以及当前缺什么。

---

## 0. 一句话结论

**编排层可以完全自动化；物理层必须先有一个通过 QC 的锚点。**

在当前验证算例（合成叠层、弱 LJ 界面）上直接开搜，AI 会在一堆被门禁拒绝的数据里
找“最优”，结果没有意义。锚点通过后，下面这套循环可以无人值守运行。

---

## 1. 角色与审核点

| 角色 | 职责 |
|---|---|
| 人类 | H0：批准锚点（几何 + 势函数 + 收敛）；H6：审核最终候选是否物理合理 |
| AI | 设计几何、生成结构、跑 3 seed、QC、排序、代理模型、提出下一批、局部优化 |
| 门禁脚本 | 判定 PASS/FAIL；AI 不得改阈值、不得跳过失败点 |

只有两个强制人工节点：

- **H0 锚点**：平面 v1 的 3 seed 必须 QC PASS，且长度/截面收敛 <5%。
- **H6 候选**：AI 提交 top-5（结构图 + TBR + 不确定度 + 收敛证据），人类判断是否合理。

中间的所有 QC、失败重试、参数点选择都由 AI 完成并记录。

---

## 2. 五阶段循环

### Phase A：锚点（H0，一次性）

1. 用 `build_geometry.py` 生成平面 `Si/Ti/Au/Ti/Si`（v1：40/20/40/20/40，界面 ±40/±20）。
2. `minimize` + `NVT 300 K` 平衡，确认无整体漂移（COM 速度 ≈ 0）。
3. `potentials.lock.json`：Ti 用 LJ、Si=Tersoff、Au=EAM；Si/Au 做体性质校验 PASS。
4. 3 seed × 120000 步，必须全部 QC PASS：
   - TotEng 漂移 ≤1%
   - dT_total >5 K
   - R² ≥0.995
   - 前后半段 TBR 差 ≤5%
   - relstd ≤10%
5. 长度/截面收敛：厚度 ×1.5、×2，TBR 变化 <5%。

**只有 H0 通过，才允许进入 Phase B。**

### Phase B：定义设计空间

一个参数点 = 一个 `scan.csv` 行：

```text
scan_id, kind, W_nm, D_nm, P_nm, t_nm, phi_deg, sided
```

- `kind`：flat / rect / trapezoid / double / rot45 / cross
- 范围由人类给定（例如 W ∈ [4,24] nm，D ∈ [1,10] nm，P ∈ [16,64] nm）
- 约束：`P > W`，`D < 层厚`，窗口仍满足 Q3–Q8

AI 用 **拉丁超立方/ Sobol** 生成第一批 12–20 个点，保证覆盖空间。

### Phase C：低保真筛选（可无人值守）

- 小细胞（16.29 Å 面内，约 1.8k 原子）
- 1 seed × 20000 步（约 60–100 s/点）
- 每个点走完整 G0–G4，失败点记录但不再用
- 目标：在 1–2 h 内筛掉明显差的形状

### Phase D：代理模型 + 主动学习

- 用已 PASS 的点拟合 GP（RBF 核）或随机森林
- 采集函数：Expected Improvement（EI），兼顾“低 TBR”和“不确定度”
- 每轮提出 6–10 个新点，跑 Phase C，更新模型
- 停止条件：连续 2 轮 EI 提升 <2%，或预算用尽

### Phase E：高保真精算

- 对代理模型 top-5 用**完整细胞**（65.16 Å，约 37k 原子）
- 3 seed × 120000 步，全部 QC PASS
- 只有这一步的数字可以进入候选报告

### Phase F：人类审核（H6）+ 局部优化

- AI 提交 top-5：结构截面图、TBR、relstd、收敛证据、与平面基准的对比
- 人类判断“物理上是否合理”（见第 6 节清单）
- 批准后，AI 在最优点附近做局部搜索（W/D/P/t 各 ±20%），直到 TBR 不再下降

## 3. 成本模型（本机串行）

| 阶段 | 体系 | 步数 | 单点耗时 | 数量 | 合计 |
|---|---|---|---|---|---|
| 锚点 | 37k | 3×120k | ~6.6 h | 1 | ~6.6 h |
| 筛选 | 1.8k | 1×30k | ~100 s | 20 | ~35 min |
| 精算 | 37k | 3×120k | ~6.6 h | 5 | ~33 h |
| 局部 | 37k | 3×120k | ~6.6 h | 6 | ~40 h |

一轮完整“筛选 + 精算”约 **2–3 天**（串行）。若修复 MPI（16 ranks），可压到 **4–6 h**。
这是当前串行的硬约束，也是为什么 Phase C 必须用小细胞。

## 4. 现在有什么、缺什么

| 能力 | 状态 |
|---|---|
| G0 前置校验（环境/几何/哈希/干跑） | ✅ 已实现并验证 |
| 建版、manifest、不可覆盖 | ✅ |
| 三种子运行、日志/退出码/超时 | ✅ |
| 后处理（q、ΔT、TBR、能量、收敛） | ✅ |
| 组级门禁 + CSV + 报告 + ledger | ✅ |
| 形状参数化预览（7 种） | ✅ |
| **生产几何生成器 `build_geometry.py`** | ✅ Si(001)/Ti(hcp)/Au, B 方案 |
| **稳定锚点（QC PASS 的平面结构）** | 🔄 3 seed × 120k 后台运行中 |
| 批量调度器（scan → run → qc） | ❌ 待实现 |
| 代理模型 + EI 提议 | ❌ 待实现 |
| 候选报告（top-5 + 结构图） | ❌ 待实现 |

**物理层缺口**（即使编排全自动也绕不过）：

1. Ti 没有多元素 MEAM；当前 Ti-LJ 只是模型，不是真实 Ti。
2. EAM/Tersoff 没有电子热导；Au 侧热导被严重低估。
3. 没有硅化物化学；Ti/Si 界面是 LJ。
4. 65 Å 面内小于 Si 声子平均自由程，需长度收敛。
5. `fix ave/chunk temp` 不扣 COM，滑移体系会高估温度。

因此，AI 找到的是**这个模型下的最优**；人类 H6 审核的是“模型最优是否也物理合理”。
不能把模型最优直接写成实验结论。

---

## 5. 需要人类提供的三件事

1. **Si 表面取向**：(001) 还是 (111)？决定晶格与槽壁刻面。
2. **Ti 相**：hcp（需要 MEAM 参数）还是 fcc-LJ 近似（当前验证方案）？
3. **图案位置**：槽刻在 Si/Ti 界面，还是 Au/Ti 界面？`t` 指 Au 膜厚还是填平厚度？

这三件事定了，`build_geometry.py` 才能写出可平衡的正式结构。

---

## 6. 人类审核候选的清单（H6）

不要只看 TBR 数字，按下面顺序看：

1. **趋势**：TBR 是否随接触面积增加而下降？随 D 增加是否先降后升（填充空洞）？
2. **单调性**：W、P、t 的变化是否给出连续趋势，还是有孤立低点（可能是噪声）？
3. **收敛**：候选点的 R²、前后半段差、relstd 是否都贴边通过？贴边通过不可信。
4. **物理图像**：截面图里槽是否被 Au 填满？有没有真空洞/悬空原子？
5. **量级**：TBR 是否在 1e-9–1e-8 m²·K/W 的合理范围？超出就是模型/单位问题。
6. **与平面基准比较**：图案化带来的降幅是否 >20%？小于 20% 可能被噪声淹没。

只有 1–6 都过，才批准进入局部优化。

## 7. 实施顺序（建议）

| 步骤 | 内容 | 谁做 |
|---|---|---|
| 1 | 确认第 5 节三件事 | 人类 |
| 2 | 写 `build_geometry.py`（平面 + 参数化槽） | AI |
| 3 | 生成平面 v1，平衡，potentials.lock，跑锚点 | AI，人类 H0 审核 |
| 4 | 写 `scan_runner.py`（批量调度） | AI |
| 5 | 写 `optimize.py`（GP + EI + 提议） | AI |
| 6 | 跑 Phase C 筛选，提交 top-5 | AI，人类 H6 审核 |
| 7 | 局部优化 + 最终候选 | AI，人类最终确认 |

第 2–6 步可以在锚点通过后连续无人值守完成。

---

## 8. 验收标准（什么叫“做到”）

- AI 能在无人干预下连续跑 ≥20 个参数点，失败点自动记录、不重试、不改阈值；
- 每轮产出 `tbr_result.csv` + `report.txt` + `ledger.csv`，全部可追溯；
- 代理模型能给出下一批点，并说明“为什么选这些点”；
- top-5 候选有结构图、TBR、不确定度、收敛证据；
- 人类审核时间 <30 min/轮；
- 最终 TBR 的模型误差范围被明确写出，不冒充实验值。

达到以上 6 条，才算“人类只审核、AI 找最优”。
